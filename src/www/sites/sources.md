`data.py` holds immutable USD planning prices and model metadata verified against linked primary sources on November 11, 2026 (all Google Cloud GPU, Cloud TPU, GKE, 12 managed API rates across Anthropic, OpenAI, and Google, and 14 open-weight model checkpoints/recipes re-read that day: Gemma 4 31B, Qwen3.8 2.4T A95B, and Kimi K3.1 Pro added; Kimi K3 upgraded). No runtime price API or GPU/TPU benchmark is implied.

## Modes and sizing

- **Simple vs. advanced**: simple mode (`preset`, `model`, `billing`, `requests`, `window`) sizes whole replicas to cover both monthly tokens and active-window daily calls across four workloads (`small-team` 1,000/day, `document-pipeline` 1,000/day batch, `department` 10,000/day, `service` 100,000/day, anchored to 5 calls/employee/day), and lists alternative plans. Batch presets (`document-pipeline` 8h) schedule active hours (`days × window`, capped at 730h/month) and default (`billing=auto`) to the cheaper of DWS Flex-start and on-demand against batch API rates (50% off); interactive presets (`small-team` 8h, `department` 8h, `service` 24h) stay on-demand with standard API rates. Advanced mode fixes the fleet (up to 100,000 replicas and 10M calls/day as calculation bounds); custom calendars/token mixes revert to `small-team` when switching back to simple mode, while MCP rejects invalid cross-mode overrides.
- **Automatic checkpoint and machine fallback**: models sort smallest-first by total then active parameters (`Qwen3.5 4B` is an L4 sizing reference, not a quality recommendation). When a plan lacks a model's default checkpoint or a workload exceeds its recipe cap, automatic setup steps to the next supported checkpoint on its lowest-cost compatible machine (preferring single-host): e.g., `Muse Spark Open`, `Mistral Large 4`, and `Qwen3.8 2.4T A95B` default to NVFP4 on A4 (`1 × a4` for Muse Spark Open and Mistral Large 4, `2 × a4` for Qwen3.8 2.4T A95B) and fall back on on-demand to BF16/FP8 on `a3-ultra`; `Nemotron 3.5 Super VL` above 16,384 context moves from G4 NVFP4 to BF16 on A3 High/Ultra. Retired IDs (`fp4`, `ops`, `kimi-k3`) show validation notices or resolve legacy URLs on the web and fail in MCP.
- **Capacity, memory, and break-even**: defaults assume 100 output tokens/s per replica at 65% utilization (monthly = `rate × replicas × running_hours × 3,600`; daily = `rate × replicas × window_s / output_tokens`, without double-applying monthly duty) and a 25% reserve over stored tensor bytes (weight floor only; KV cache, activations, prefill, and latency require pilot measurements; output budgets include reasoning). Fixed-fleet break-even is the first whole monthly request count where API spend reaches compute + GKE while fitting monthly/daily capacity and multi-host pilot gates.
