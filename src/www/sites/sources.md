# LLM hosting snapshot · 2026-10-12

`data.py` holds immutable USD planning prices and checkpoint sizes verified against the linked primary sources on October 12, 2026. Review API rates by November 12 and cloud prices/availability before a commitment. No runtime price API or GPU benchmark is implied.

## Modes and sizing

Simple mode takes a workload, optional daily call count, model, plan, and usage window. Models are ordered by parameter count; Qwen3.5 4B is a compact L4 reference, not a task-quality recommendation. The selected checkpoint determines hardware compatibility. Mistral Small 4 defaults to economical NVFP4, with a 16,384-token context cap on G4; advanced precision comparisons independently select compatible hardware and expose both cost and serving trade-offs.

Teams default to an eight-hour window and always-on nodes. Support services use 24 hours. Single jobs default to one hour; document and scheduled pipelines to eight. These batch presets schedule nodes inside their active windows: running hours = active days × window, capped at 730/month. The GKE cluster stays up for the month. On-demand bills running hours; commitments bill the full 730 hours. Startup and shutdown must fit the operating budget, and no failover replica is added. Presets are illustrative examples, not customer observations. Output includes reasoning; brief-answer budgets should be increased for heavy thinking or retries.

Capacity uses 100 generated tokens/s per complete model copy, with 65% usable, independently of GPU/model. Monthly capacity = rate × replicas × running hours × 3,600. Daily capacity = rate × replicas × usage-window seconds / output tokens per request. These are separate constraints: the monthly duty fraction is not applied again inside each active window. Running hours are assumed schedulable where work happens. Simple mode rounds up whole copies to cover both constraints; advanced mode keeps the fleet fixed. Prompt processing, KV cache, concurrency, and response latency need measurement. No speed ranking is implied.

Simple results lead with the cost decision and rounded budgets. Exact figures, half-to-double throughput sensitivity, running time, and method/source notes follow in always-open sections; the setup and running-time section sits directly above the method. The model picker lists each model's size in parameters, smallest first by total then active parameters. The sensitivity range resizes the fleet under the same checkpoint, hardware, and schedule. Simple `requests` overrides only call volume; blank web input uses the preset. `window=auto` uses its window. Shareable URLs serialize resolved values. Advanced URLs preserve exact inputs; the 100,000-replica input limit covers every automatic fleet at the 10 million daily-call limit. This is a calculation bound, not an assertion of available cloud capacity. A custom token mix or calendar returns to the small-team example in simple mode while preserving daily volume. Explicit simple mode rejects other advanced overrides through MCP and reports fallback on the website.

API comparison uses identical token budgets, not equivalent quality. Fixed-fleet break-even is the first whole monthly call count whose API bill reaches compute plus GKE. Each threshold must fit monthly and daily capacity and satisfy multi-host pilot requirements. The compact view omits unreachable numeric thresholds. Resizing or adding operating costs changes break-even. No runtime benchmark or task-quality result is implied.

Stored tensor sizes include mixed precision and quantization scales. They are a weight-memory floor, not allocated runtime memory. The reserve does not calculate KV cache, activations, model loading, graph capture, or prefill; context/concurrency must be measured. Capacity checks both daily demand and monthly tokens. Reported throughput and pilot evidence remain caller assumptions, not server benchmarks. Unsupported hardware/format/topology combinations cannot pass the shared cost/capacity gate and are rejected by MCP.

A4 Flex-start is $64.44/hour. Its provisioning queue and bounded run duration do not establish continuous serving availability. The calculator does not stack discounts. Commitments pay for the full term even when nodes are idle and require GPU reservations: [GPU commitment requirements](https://cloud.google.com/products/compute/gpus-pricing), [committed-use billing](https://docs.cloud.google.com/compute/docs/instances/signing-up-committed-use-discounts).

The [GKE cluster fee](https://cloud.google.com/kubernetes-engine/pricing) remains $0.10/hour; no free-tier credit is assumed. Monthly totals include GPU compute and this fee only. Additional disks, network transfers, load balancers, licenses, taxes, and operations are excluded. The operations-budget parameter has been removed: old web URLs show an explanatory message and MCP rejects it.

[Machine specifications](https://docs.cloud.google.com/compute/docs/accelerator-optimized-machines), [GKE Standard GPU support](https://docs.cloud.google.com/kubernetes-engine/docs/how-to/gpus), and [GKE inference guidance](https://docs.cloud.google.com/kubernetes-engine/docs/best-practices/machine-learning/inference) support the L4/G2 and RTX PRO 6000 Blackwell Server Edition/G4 entries. G2 uses a 48 GiB host configuration to leave more model-loading room than the smallest 16 GiB VM. Driver support, checkpoint format, host RAM, and KV cache still require a pilot.

Sonnet and Opus retain standard rates across their context windows. All three 5.5 models require at least 512 cache tokens. Standard global routing is assumed; residency, fast mode, and tool premiums are excluded.
- [Gemini pricing](https://ai.google.dev/gemini-api/docs/pricing#gemini-3.8-flash), [model limits](https://ai.google.dev/gemini-api/docs/models/gemini-3.8-flash), and [cache rules](https://ai.google.dev/gemini-api/docs/caching): introductory input, output, cache-read and $0.50/M token-hour explicit cache storage prices double January 1, 2027. Input and output limits are separate; no unverified combined-context cap is imposed. Output includes thinking tokens. The calculator models five-minute explicit GenerateContent caches with a 4,096-token minimum, not guaranteed implicit cache hits.
- [Astra model pricing](https://developers.openai.com/api/docs/models/gpt-6-astra): input over 272,000 tokens doubles input/cache rates and multiplies output by 1.5 for the entire request. API rates are separate from subscriptions and tool charges.

Batch rates are half the standard token rates. Cache and batch discounts are modeled separately; commitments never discount API calls. Task-quality rows follow the returned baseline order, with one row for the fleet and one per API. Acceptance percentages allow zero or values from 0.0000001 through 100, keeping cost division and chart arithmetic finite. Smaller nonzero values, including values that underflow to zero, produce web validation feedback and are rejected by MCP.

[Native FP8 W8A8](https://docs.vllm.ai/en/latest/features/quantization/llm_compressor/fp8/) uses Ada/Hopper/Blackwell; A100 is excluded from this selection. FP8 weight-only Marlin fallback is a separate implementation, not the modeled native W8A8 path. NVFP4 selections use native Blackwell hardware except Inkling’s explicitly documented H200 emulation path. INT4 AWQ/GPTQ remains recognized for old URLs but no unsourced converted checkpoint is offered. Multi-host memory aggregation on single-GPU G2/G4/A2 nodes is unsupported in this catalog; pilot values cannot override that boundary. Flex-start is available only for queued batch comparisons.

[Mistral Large 4](https://mistral.ai/news/mistral-large-4/) is an API public preview, with weights announced for late October (the [upcoming checkpoint](https://huggingface.co/mistralai/Mistral-Large-4-1T-A52B) states October 31). It is not selectable for GKE until weights, runtime support, and compatible machine pricing are verified. No guessed self-hosting price or temporary API preview discount is included.
