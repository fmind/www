How to reduce it

  • Enable only the tools a task needs. GitHub supports toolsets and individual tools. Tool sizes vary, so count the selected definitions.
  • Load definitions on demand. Claude Code tool search and provider tool search defer definitions until the model needs them, at the cost of extra search steps.
  • Cache the stable prefix. Prompt caching bills repeated definitions at a fraction of the input price, but they still fill the context window.
  • Prefer CLI skills where they fit. Agent Skills progressive disclosure keeps only short metadata in context and loads instructions when used.

Method and limitations

  • Tokens per request add the measured tool definitions of the selected servers: name, description and input schema, serialized as compact JSON and counted with tiktoken 0.14.0 (o200k_base). Monthly tokens multiply by requests per day and 30 days.
  • Cost multiplies tokens by each model's standard input price. Context used divides tokens by the model's input limit. Prices come from the same dated snapshot as the LLM hosting comparison.
  • Excluded: caching discounts, instructions, history, tool results, output and reasoning, client wrappers and output schemas. Each provider tokenizes differently; measure your own client before budgeting.
