How to reduce it

  • Filter for the task. Enable only needed tools or toolsets. GitHub documents toolsets and individual tool selection. Count the selected schemas: fewer tools do not always mean proportionally fewer tokens.
  • Load definitions when needed. Claude Code tool search defers definitions. Provider tool search has its own setup and limits. Measure loaded definitions, retained context and extra calls.
  • Cache stable prefixes. Follow provider cache requirements; inspect actual usage counters. Stable definitions may be cheaper on a hit but still occupy context.
  • Use CLI skills where they fit. Agent Skills progressive disclosure keeps initial metadata small and loads instructions later. Include the shell tool, loaded help and command output in a complete measurement.

The MCP tools specification defines tool discovery and schemas. The host decides what reaches the model; tools/list bytes are not necessarily model context.

Formulas and limits
  • All-tools = sum of full catalogs for servers with an enabled count above zero. Filtered = sum of catalog tokens × enabled / available tools, rounded up once. Search = discovery scaffold + filtered × loaded %, rounded up. CLI = skill scaffold + average loaded help.
  • Context share = tokens/request ÷ context window × 100. No-cache session = tokens/request × requests/session × input price ÷ 1,000,000.
  • Cache hits = (requests/session − 1) × hit %. Stable tokens = discovery scaffold for search; otherwise the whole block, including CLI help, is assumed unchanged. Eligible cached session = [stable tokens × ((requests − hits) × input price × write multiplier + hits × cache-read price) + remaining tokens × requests × input price] ÷ 1,000,000. Only stable tokens plus other stable prefix count toward the minimum. Without an eligible stable prefix, use no-cache cost. Provider alignment is not modeled.
  • Day = session × sessions/workday. Month = day × workdays/month. Sessions start cold. Other stable prefix tokens count toward cache eligibility only; their context and cost are excluded. Cache storage fees, output/reasoning, tool results and extra search calls are excluded.
  • One reference tokenizer makes catalogs comparable; it does not reproduce every provider's tokenizer, tool wrappers or hidden tokens. These are planning estimates, not measured production behavior, latency, quality or a complete bill.
