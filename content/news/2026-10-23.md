## Highlights

- [Introducing Agent Compute Engine and expanding agent governance](https://cloud.google.com/blog/topics/ai-infrastructure/introducing-agent-compute-engine-and-expanded-agent-governance): Isolates every autonomous agent session inside a dedicated microVM backed by Titanium hardware roots of trust and open-sources the Agent Substrate GKE runtime for 10x higher multi-agent workload density alongside unified fleet governance.
- [Agent Compute Engine deep dive](https://cloud.google.com/blog/topics/ai-infrastructure/agent-compute-engine-deep-dive): Details how copy-on-write memory sharing, fast checkpoint/restore across idle inference waits, dm-verity read-only root filesystems, and zero-credential guest sandboxes scale hundreds of millions of isolated agent sessions.
- [Architecting Governed, Self-Evolving AI Agents on Google Cloud](https://developers.googleblog.com/architecting-governed-self-evolving-ai-agents-on-gemini-agent-platform): Combines the Agent Development Kit (ADK), BigQuery telemetry, Model Armor guardrails, and Cloud KMS cryptographic identities on the Gemini Enterprise Agent Platform to build self-evolving agents that remediate production outages in seconds.

## More

- [Introducing TorchTPU](https://pytorch.org/blog/introducing-torchtpu): Google and Meta open-source a native PyTorch PrivateUse1 backend for Cloud TPUs supporting out-of-the-box eager execution, DeferAndFuse HBM optimization, torch.compile, and direct integration with vLLM, SGLang, and TorchTitan.
- [Donating Agent Skills to the Agentic AI Foundation](https://www.anthropic.com/news/donating-agent-skills-to-the-agentic-ai-foundation): Contributes the open SKILL.md standard for packaging on-demand agent instructions, scripts, and domain workflows to the Linux Foundation's Agentic AI Foundation alongside MCP for vendor-neutral governance and cross-platform portability.
- [Knowledge Catalog: self-learning context enrichment for AI agents](https://cloud.google.com/blog/products/data-analytics/knowledge-catalog-self-learning-context-enrichment-for-ai-agents): Evolves Dataplex into a self-learning context engine that uses Gemini to continuously mine schemas, query logs, and Looker semantic models, exposing governed metadata and verified queries to AI agents via sub-second Context APIs and MCP tools.
- [Expanding Claude availability and deployment choice on Google Cloud](https://cloud.google.com/blog/products/ai-machine-learning/expanding-claude-availability-on-google-cloud): Brings Anthropic-managed Claude deployments to general availability on Google Cloud alongside existing Google-managed Vertex AI endpoints, letting enterprises pair direct Anthropic platform access with consolidated cloud billing and infrastructure.
- [How bug bounty sharpens one researcher’s security skills](https://github.blog/security/how-bug-bounty-sharpens-one-researchers-security-skills): Profiles security researcher @r31n's methodology for discovering complex vulnerabilities in GitHub Enterprise Server through manual source-to-sink code analysis, state-transition testing, and multi-step exploit chaining rather than automated scanners.
- [Real-time speech translation in Google Meet expands to 63 languages with automatic language detection](https://workspaceupdates.googleblog.com/2026/10/real-time-speech-translation-in-google-Meet-expands-to-63-languages-with-automatic-language-detection.html): Scales continuous, voice-preserving speech translation across 63 languages in Google Meet with real-time automatic spoken-language detection to eliminate manual toggling during multilingual calls.
- [The AI cyber arms race is escalating fast](https://www.reddit.com/r/singularity/comments/1xcc2cx/the_ai_cyber_arms_race_is_escalating_fast): Community discussion examining threat intelligence reports on automated exploit campaigns and state-sponsored AI agent swarms compromising cloud tenants in under three hours.
