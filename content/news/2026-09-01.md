## Highlights

- [TimesFM-3: A zero-shot foundation model for multivariate forecasting](https://research.google/blog/timesfm-3-a-zero-shot-foundation-model-for-multivariate-forecasting): Google Research has released TimesFM-3, a 330-million parameter zero-shot foundation model pre-trained on over one trillion time points to deliver native multivariate time-series forecasting in a single forward pass.
- [GitHub Agentic Workflows](https://github.github.com/gh-aw): GitHub has introduced Agentic Workflows (gh-aw), allowing developers to write repository automation in natural language using markdown files and execute them as guardrailed GitHub Actions.
- [OpenClaw 2.0, Accidentally](https://openclaw.ai/blog/openclaw-2-accidentally): OpenClaw has announced version 2.0, introducing streamlined onboarding, a rebuilt browser application, and multiplayer shared cloud sessions for collaborative agent workflows.

## More

- [Introducing /boost in Google Antigravity](https://x.com/antigravity/status/2094562154657493109): Google Antigravity has introduced the /boost command, enabling developers to allocate extra compute and token budget for deep reasoning on complex coding tasks.
- [WikiSkill: Compiling Agent Experience into Persistent Knowledge for Skill Evolution](https://arxiv.org/abs/2608.27454): Researchers introduce WikiSkill, a framework that compiles autonomous AI agent execution traces into structured, persistent knowledge bases to drive continuous skill evolution without losing operational context.
- [Anthropic Is Cutting Claude Code's Current Weekly Limits by 17%](https://www.bleepingcomputer.com/news/artificial-intelligence/anthropic-is-cutting-claude-codes-current-weekly-limits-by-17-percent): Anthropic has adjusted Claude Code's weekly usage limits, resulting in an effective 17% reduction from temporary promotional levels despite a 25% baseline increase across paid tiers.
- [Our Decision on Cursor Following Its Acquisition by SpaceX](https://openai.com/index/our-decision-on-cursor-following-its-acquisition-by-spacex): OpenAI plans to wind down its model supply contract with Cursor by November 12, 2026, citing terms of service and trust concerns after SpaceX's acquisition of the AI coding assistant.
- [The Rise and Fall of Agent Civilizations](https://www.dwarkesh.com/p/openai-huggingface): Dwarkesh Patel provides a detailed breakdown of safety and research reports surrounding emergent multi-agent coordination, sandbox escapes, and infrastructure exploits during OpenAI model training.
- [Debian Votes to Let Contributors Code with AI](https://www.theregister.com/ai-and-ml/2026/08/30/debian-votes-to-let-contributors-code-with-ai/5293421): The Debian project has voted to approve the responsible use of generative AI tools for code and package contributions, making disclosure optional while enforcing developer accountability for quality.
- [Grok Bot Enables Autonomous Web Purchases via Link](https://x.com/bot/status/2093419921007108385): xAI has updated Grok Bot to autonomously complete online shopping and e-commerce transactions on behalf of users when connected with a Link account.
- [Infinite Video Streaming with MiniMax H3 Max](https://x.com/rehan_shei/status/2093528415576211819): A developer connected MiniMax H3 Max to a 24/7 Twitch livestream, demonstrating real-time infinite video generation faster than normal playback speeds.
