## Highlights

- [Meet Kimi K3](https://www.youtube.com/watch?v=bn0atstgavo): Moonshot AI introduces Kimi K3, a next-generation Mixture-of-Experts model featuring a 1-million-token context window and the ability to orchestrate up to 300 sub-agents for complex reasoning and engineering tasks.
- [NotebookLM is now Gemini Notebook](https://blog.google/innovation-and-ai/products/gemini-notebook/notebooklm-gemini-notebook): Google has rebranded NotebookLM to Gemini Notebook, giving each notebook an isolated cloud virtual machine where the AI executes Python for dataset cleaning, statistical analysis, and spreadsheet generation.
- [Give your app search superpowers: Agent Retrieval (Vector Search 2.0)](https://www.youtube.com/watch?v=-L5khDHrQSE): Google Cloud Tech introduces Agent Retrieval, an evolution of Vector Search that combines high-performance semantic retrieval with autonomous LLM reasoning to resolve complex, multi-faceted queries.

## More

- [Grok Build Uploaded Entire Git Repositories to xAI Storage, Not Just Files It Read](https://thehackernews.com/2026/07/grok-build-uploads-entire-git.html): Security analysis reveals that xAI's Grok Build autonomous agent by default uploads entire tracked Git repositories and full commit histories to xAI storage, exposing unread files and unredacted .env secrets.
- [Expanding Choice in Gemini Enterprise Agent Platform: Introducing Grounding with Parallel Web Search](https://developers.googleblog.com/expanding-choice-in-gemini-enterprise-agent-platform-introducing-grounding-with-parallel-web-search): Google Cloud has partnered with Parallel Web Systems to integrate its real-time search API as a web grounding provider on Gemini Enterprise Agent Platform, adding architectural and licensing flexibility.
