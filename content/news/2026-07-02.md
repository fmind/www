## Highlights

- [Build agentic full-stack apps with Genkit](https://developers.googleblog.com/build-agentic-full-stack-apps-with-genkit): Google announces Genkit Agents, a new Agents API that simplifies full-stack conversational AI development with built-in message history, streaming, persistence, and human-in-the-loop support for TypeScript and Go.
- [Why we built ADK 2.0](https://developers.googleblog.com/why-we-built-adk-20): Google introduces Agent Development Kit (ADK) 2.0, adding structured workflows and deterministic execution to Python and Go to bridge autonomous AI capabilities and strict, cost-effective business logic.
- [Beyond Static Prompts: Building Scale-Proof, Polymorphic Multi-Agent Systems with Google's ADK](https://cloud.google.com/blog/topics/developers-practitioners/beyond-static-prompts-with-google-adk): Google Cloud explains how to build scale-proof, polymorphic multi-agent systems with Google's ADK by implementing dynamic, metadata-driven validation to solve context bloat and attention diffusion.
