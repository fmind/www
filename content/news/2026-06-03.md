## Highlights

- [GitHub Copilot app: The agent-native desktop experience](https://github.blog/news-insights/product-news/github-copilot-app-the-agent-native-desktop-experience): GitHub launched the GitHub Copilot desktop app in technical preview, an agent-native hub that lets developers run and manage multiple parallel AI agents in isolated Git worktrees.
- [Build AI agents faster with GCS (Google Cloud Storage) MCP server](https://cloud.google.com/blog/topics/developers-practitioners/build-ai-agents-faster-with-gcs-google-cloud-storage-mcp-server): Google Cloud released an official Model Context Protocol server for Google Cloud Storage, letting AI agents securely list, read, write, and manage storage resources via natural language prompts.
- [Introducing Spanner Graph algorithms](https://cloud.google.com/blog/products/databases/introducing-spanner-graph-algorithms): Google Cloud introduced Spanner Graph algorithms in preview, running scalable graph mining tasks such as fraud detection and social network analysis directly within Spanner using GQL and SQL.

## More

- [Automate SAP order-to-cash with multi-agent AI & Google Agent Development Kit (ADK)](https://www.youtube.com/watch?v=z4CXn4CKHQI): Google Cloud Tech demonstrates how to automate brittle, legacy SAP order-to-cash RPA workflows using API-based multi-agent AI systems orchestrated via the Google Agent Development Kit and Model Context Protocol.
- [Gemini Spark is the most impressive and terrifying AI experience I’ve had yet](https://www.theverge.com/ai-artificial-intelligence/941388/gemini-spark-ai-agent-trip-planning): Google is rolling out Gemini Spark, an always-on agentic AI platform that executes complex tasks across the web and user devices using personal data, raising notable privacy concerns.
- [Microsoft Scout is a new AI personal assistant built on OpenClaw](https://www.theverge.com/news/939713/microsoft-scout-assistant-openclaw): Microsoft introduced Microsoft Scout, an always-on personal assistant built on the open-source OpenClaw project and Microsoft 365 that automates calendars, expenses, and travel in a sandboxed enterprise environment.
- [Codex for knowledge work](https://openai.com/index/codex-for-knowledge-work): OpenAI details how Codex has grown from a programming tool into an agentic productivity platform used by millions of knowledge workers to automate processes, analyze data, and build workspaces.
- [Google Workspace Updates: Introducing the ability to loop over a list of items in Workspace Studio](https://workspaceupdates.googleblog.com/2026/06/introducing-ability-to-loop-over-list-of-items-in-Workspace-Studio.html): Google added a "Repeat for each" step in Google Workspace Studio that loops over lists, such as Google Sheets rows or Gemini outputs, to run sequential substeps.
