## Highlights

- [ARC-AGI-3 Launches - AI Agents Must Learn, Not Memorize](https://awesomeagents.ai/news/arc-agi-3-interactive-benchmark/): The ARC Prize Foundation introduced ARC-AGI-3, an interactive benchmark testing an agent's ability to learn rules in unfamiliar environments, alongside an open-source Python toolkit.
- [Build with Lyria 3, our newest music generation model](https://blog.google/innovation-and-ai/technology/developers-tools/lyria-3-developers/): Google launched Lyria 3 and Lyria 3 Pro in public preview, offering developers high-fidelity music generation with granular controls via the Gemini API and AI Studio.
- [Closing the knowledge gap with agent skills](https://developers.googleblog.com/closing-the-knowledge-gap-with-agent-skills/): Google DeepMind introduced "agent skills" as a lightweight method to provide coding agents with up-to-date SDK knowledge and best practices, showing significant performance gains.
