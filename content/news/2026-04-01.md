## Highlights

- [ADK Go 1.0 Arrives!](https://developers.googleblog.com/adk-go-10-arrives/): Google has launched version 1.0 of the Agent Development Kit (ADK) for Go, featuring OpenTelemetry integration for deep tracing, a new plugin system for self-healing logic, and human-in-the-loop safety guardrails.
- [Improve Coding Agents’ Performance with Gemini API Docs MCP and Agent Skills](https://blog.google/innovation-and-ai/technology/developers-tools/gemini-api-docsmcp-agent-skills/): Google has launched the Gemini API Docs MCP and Developer Skills to provide coding agents with real-time access to up-to-date documentation and best practices, significantly increasing their accuracy and efficiency.
- [Build with Veo 3.1 Lite, Our Most Cost-Effective Video Generation Model](https://blog.google/innovation-and-ai/technology/ai/veo-3-1-lite/): Google DeepMind has released Veo 3.1 Lite, a cost-effective video generation model available in the Gemini API that allows developers to build high-volume video applications with professional capabilities.
