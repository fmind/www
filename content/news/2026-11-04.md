## Highlights

- [google/elephant-goldfish-model](https://github.com/google/elephant-goldfish-model): Open-sources an Apache-2.0 plugin that pairs deep-context agents for drafting design specifications with zero-context subagents to expose unstated architectural assumptions and blind spots before code generation.
- [Modernizing 40-year-old scientific code with Gemini 4 Argon](https://antigravity.google/blog/modernizing-40-year-old-scientific-code-with-gemini-4-argon): Migrates 174,000 lines of legacy Fortran ocean modeling code into memory-safe Rust in 59 minutes using Google Antigravity and Gemini 4 Argon, uncovering six bugs and halving memory consumption.
- [Scaling Git at OpenAI](https://openai.com/index/scaling-git-at-openai): Introduces Pando, a Git-compatible storage backend powered by immutable packfiles and causal consistency to support high-concurrency branch updates and automated repository operations from Codex agents.

## More

- [Cost per task: Using cheap classifiers to route across Gemini models and thinking levels](https://developers.googleblog.com/cost-per-task-using-cheap-classifiers-to-route-across-gemini-models-and-thinking-levels): Demonstrates how to optimize autonomous coding agent economics by using fast, single-pass classifiers to route agent decisions across Gemini model tiers and dynamic thinking budgets.
- [Automating agentic AI Well-Architected reviews with the AWS Agentic AI Lens](https://aws.amazon.com/blogs/architecture/automating-agentic-ai-well-architected-reviews-with-the-aws-agentic-ai-lens): Shows how Smarsh codified the AWS Well-Architected Agentic AI Lens into an agent skill to audit production workloads against 150 best practices directly from GitHub repositories.
- [The ROI of Agentic Remediation: Results with Wiz Green Agent](https://www.wiz.io/blog/green-agent-agentic-remediation): Reports enterprise results from Wiz Green Agent, an autonomous security remediation system that maps cloud runtime findings to code owners and generates pull requests to fix vulnerabilities.
- [Our organizations are being DDoSed from the inside](https://karrisaarinen.com/posts/our-organizations-are-being-ddosed-from-the-inside): Argues that AI coding agents produce changes faster than organizations can review and understand them, creating an internal denial of service that undermines leadership's ability to steer product direction.
- [Shop freezers in seven European countries hit by cyber-attack](https://www.bbc.com/news/articles/cq1kd1nee80eo): Reports that a cyberattack switched connected commercial supermarket refrigeration systems across seven European countries into forced defrost mode, spoiling perishable inventory across Delhaize and regional chains.
- [The worst week in cybersecurity history... so far](https://www.youtube.com/watch?v=k2ruCf_z75I): Summarizes a series of high-impact cybersecurity incidents, covering unreleased Claude model capabilities gaining Linux root access, cryptocurrency treasury thefts, and developer tool supply chain compromises.
