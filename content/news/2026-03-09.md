## Highlights

- [Building Claude Code with Boris Cherny](https://www.youtube.com/watch?v=julbw1JuAz0): Boris Cherny discusses the architecture and development of Claude Code, Anthropic’s agentic CLI tool that enables developers to perform complex coding tasks, terminal operations, and repository-wide edits through a natural language interface.
- [Grounding your AI Agents with Google Search and Maps](https://www.youtube.com/watch?v=5h-bqNpcqvU): This session demonstrates how developers can use Vertex AI to ground Gemini models with real-time Google Search and Maps data to reduce hallucinations and build location-aware AI agents for complex geospatial queries.
- [Common Mistakes With Vibe Coded Websites](https://www.youtube.com/watch?v=DNSXlBmukck): This Y Combinator design review highlights technical and UX pitfalls in AI-generated "vibe-coded" websites, such as poor accessibility, broken mobile layouts, and missing metadata, while providing advice on how to use LLMs to build production-ready applications.

## More

- [Looker's Product Roadmap for Trusted AI](https://www.youtube.com/watch?v=dHqALWJG9oE): Google Cloud outlines the roadmap for Looker’s AI integration, focusing on conversational analytics and automated LookML generation that allow data developers to build governed, natural-language-ready data platforms.
